# بسته استقرار SEYED PREMIUM

فایل `bot.py` همان فایل ارسالی شماست و محتوایش تغییر نکرده است.

## نکته مهم
این بسته هنوز به‌تنهایی آماده اجرا نیست، چون فایل اصلی به ماژول‌های `ui_config.py`، `service_menu.py` و `stars_menu.py` وابسته است. فایل‌های اصلی این ماژول‌ها را هم بدون تغییر در همین پوشه قرار دهید؛ وگرنه ربات هنگام شروع خطای import می‌دهد.

## راه‌اندازی روی میزبان سازگار با Render
1. همه فایل‌های پروژه را در یک مخزن GitHub قرار دهید.
2. یک Background Worker از مخزن بسازید یا از تنظیمات `render.yaml` استفاده کنید.
3. متغیر محیطی `BOT_TOKEN` را در پنل میزبان تنظیم کنید؛ توکن را داخل کد یا GitHub نگذارید.
4. دستور نصب: `pip install -r requirements.txt`
5. دستور اجرا: `python start.py`

## مهم درباره دیتابیس
SQLite در این کد استفاده می‌شود. در میزبان‌های دارای دیسک موقت، داده‌ها ممکن است با redeploy یا restart از بین بروند؛ برای فروش واقعی، دیسک پایدار یا دیتابیس پایدار میزبان را تنظیم کنید.
